# 📊 Emoji Trends - Internet Museum

An interactive website tool/experience in neal.fun style showing emoji punctuation trends across the internet from 2010 to 2025.

## 🎯 Features

- **Interactive Timeline Explorer**: Drag the slider to explore emoji trends from 2010-2025
- **Dynamic Data Visualization**: View the top 6 most popular emojis for each year with usage statistics
- **Trend Statistics**: Real-time updates showing total usage, most popular emoji, and annual growth rate
- **Historical Context**: Learn about the cultural and technological factors that shaped emoji evolution each year
- **Usage Trends Chart**: Interactive canvas-based line graph showing emoji usage growth over time
- **Responsive Design**: Beautifully optimized for both desktop and mobile devices
- **Neal.fun Aesthetic**: Clean, colorful design with smooth animations and gradient backgrounds

## 🚀 Getting Started

### Quick Start

1. Clone the repository:
```bash
git clone https://github.com/aicoder2009/emojitrends.git
cd emojitrends
```

2. Open `index.html` in your web browser:
   - **Option 1**: Double-click the `index.html` file
   - **Option 2**: Use a local server:
     ```bash
     # Python 3
     python3 -m http.server 8000
     
     # Python 2
     python -m SimpleHTTPServer 8000
     
     # Node.js (with http-server)
     npx http-server
     ```
   - **Option 3**: Use VS Code Live Server extension

3. Explore emoji trends by dragging the timeline slider!

## 🎨 How It Works

### Timeline Interaction
- Use the timeline slider to travel through years 2010-2025
- Watch as emoji data updates in real-time
- See which emojis dominated different eras

### Data Insights
The website tracks:
- **Usage Statistics**: Billions of emoji uses per year
- **Popular Emojis**: Top 6 emojis for each year
- **Growth Trends**: Year-over-year growth percentages
- **Historical Events**: Key moments in emoji history
